# E-commercereact
1. Page purpose
Dashboard (dashboard/page.tsx)

Main layout of your admin panel.

Will include Sidebar + Navbar + content area.

Could show summary stats (orders, customers, products).

Customer pages (dashboard/customers/page.tsx)

List of all customers.

Could include search/filter functionality.

Each customer can link to a or edit page.

Product pages (dashboard/products/page.tsx)

Display all products in a grid or table.

Each product can have a card showing  name, price, and stock.

Could include edit/delete functionality.
